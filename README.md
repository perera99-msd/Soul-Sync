## Overview

Welcome to the Soul Sync Events official website repository!  
This project delivers a fully responsive web experience for Soul Sync, a Melbourne-based EDM (Electronic Dance Music) organizer. Dive into Aussie rave culture with modern design and seamless performance.

**Tech Stack:**  
- **Framework:** [React](https://react.dev/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **Languages:** HTML5, CSS3, JavaScript

## Features

- 🌐 **Responsive Layout:** Optimized for mobile, tablet & desktop
- 🎉 **Event Highlights:** Showcase upcoming events, lineups and galleries
- 🚀 **Fast Performance:** Leveraging Vite for rapid development & builds
- 🎵 **Modern UI:** Sleek, vibrant design echoing EDM energy
- 🔦 **Night Mode:** Easy on the eyes for late-evening browsing (*if implemented*)
- 🗺️ **Contact & Location:** Event details, contact forms and Google Maps embedding (*as needed*)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```sh
git clone https://github.com/perera99-msd/Soul-Sync.git
cd Soul-Sync
npm install
```

### Development

```sh
npm run dev
```

- Open [http://localhost:5173](http://localhost:5173) to view in browser.

### Build For Production

```sh
npm run build
```

- The build output will be in the `dist` folder.
